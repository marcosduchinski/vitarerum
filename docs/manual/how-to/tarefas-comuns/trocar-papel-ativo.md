# Como trocar o papel ativo

## Objetivo

Alternar entre os grupos atribuídos à mesma conta para trabalhar com as
permissões e filas corretas.

**Disponível para:** utilizadores com mais de um grupo

**Onde começar:** seletor **“Active role”** na barra superior

**Tempo aproximado:** menos de 1 minuto

## Passo a passo

1. Localize o seletor de papel na barra superior. Ele só aparece quando a conta
   possui mais de um grupo.
2. Escolha **“External researcher”**, **“Collections management”**,
   **“Curatorial”**, **“Direction”** ou **“Administrator”**, conforme a tarefa.
3. Aguarde o redirecionamento para o Dashboard.
4. Confirme o menu e volte a abrir o recurso em que pretende trabalhar.

## Resultado esperado

Os pedidos seguintes usam o novo papel, e menus, filas, TODOs e ações são
recalculados de acordo com ele. A troca não termina a sessão.

## Atenção

> Confirme o papel antes de atribuir, decidir, publicar ou administrar. Alguns
> dados pessoais, como TODOs, pertencem também ao papel que os criou.

> Ter vários papéis não combina automaticamente as permissões: cada ação é
> validada apenas com o papel ativo naquele momento.

## Se algo não funcionar

| Situação | O que verificar ou fazer |
| --- | --- |
| O seletor não aparece | A conta possui apenas um grupo; contacte a administração se faltar uma atribuição autorizada |
| Um menu desapareceu | Confirme se escolheu o papel correto e volte a abrir o recurso a partir do menu |
| Um TODO ou uma fila ficou vazio | Esses conteúdos podem pertencer ao papel anteriormente ativo |
| Recebe **“Forbidden”** | Troque para um papel autorizado; a recusa de permissão não termina a sessão |
