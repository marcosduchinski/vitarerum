# Como corrigir documentos de um pedido público

## Objetivo

Substituir documentos incorretos ou anexar documentos em falta depois de a
equipa de coleções pedir uma correção, sem ter de apresentar uma nova proposta.

**Disponível para:** requerente de um pedido público que tenha recebido uma
ligação de correção por email

**Onde começar:** ligação para `/submit-proposal/edit?token=...` recebida por
email

**Tempo aproximado:** 5 a 15 minutos, além do tempo necessário para preparar os
ficheiros

## Antes de começar

- Abra a mensagem enviada pela equipa de coleções e leia o pedido de correção.
- Prepare um ficheiro para cada documento indicado.
- Use PDF, JPG, JPEG, PNG ou DOCX, até 10 MB por ficheiro.
- Confirme que cada ficheiro abre corretamente e corresponde ao tipo pedido.

A ligação tem um prazo próprio, apresentado no ecrã, e só permite alterar os
documentos abrangidos pelo pedido de correção. Não a partilhe com outras
pessoas.

## Compreender o ecrã

Depois de abrir a ligação, o cabeçalho **“Corrija os seus documentos”** mostra o
número de referência da proposta. O resumo apresenta o estado atual e a data e
hora em que a ligação expira.

Cada cartão de correção contém:

- o tipo de documento escrito pela equipa;
- a indicação **“Substituir documento”** ou **“Anexar documento em falta”**;
- o motivo da correção;
- o estado do item;
- o campo para escolher o novo ficheiro.

Trate cada cartão separadamente. Um ficheiro carregado para um tipo não resolve
os restantes pedidos.

## Passo a passo

### 1. Verificar o pedido

1. Abra a ligação de correção recebida por email.
2. Confirme o número de referência apresentado no cabeçalho.
3. Verifique a data indicada em **“A ligação expira”**.
4. Leia o tipo e o motivo de todos os documentos pedidos antes de carregar
   qualquer ficheiro.

### 2. Substituir um documento incorreto

Num cartão com a indicação **“Substituir documento”**:

1. Leia o motivo apresentado pela equipa, por exemplo documento ilegível ou
   incompleto.
2. Em **“Ficheiro de substituição”**, escolha a versão corrigida.
3. Confirme o nome do ficheiro selecionado.
4. Selecione **“Carregar ficheiro”** e aguarde até o carregamento terminar.

Ao carregar o substituto, o sistema substitui o documento assinalado. Não é
necessário selecionar **“Remover”** antes de carregar a nova versão.

Se usar **“Remover”**, a remoção ocorre imediatamente, mas não resolve o pedido
de correção: ainda terá de carregar um ficheiro de substituição antes de
concluir.

### 3. Anexar um documento em falta

Num cartão com a indicação **“Anexar documento em falta”**:

1. Em **“Ficheiro do documento”**, escolha o ficheiro correspondente ao tipo
   indicado no cartão.
2. Confirme cuidadosamente o ficheiro selecionado.
3. Selecione **“Carregar ficheiro”**.
4. Aguarde até o documento aparecer com a indicação **“Carregado”**.

### 4. Concluir as correções

1. Percorra novamente todos os cartões.
2. Confirme que carregou um ficheiro para cada documento em falta e uma nova
   versão para cada substituição pedida.
3. Selecione **“Submeter documentos corrigidos”**.
4. Aguarde até aparecer **“Documentos submetidos”**.

Carregar os ficheiros não conclui, por si só, o processo. É indispensável usar
**“Submeter documentos corrigidos”** para notificar a equipa e fechar o pedido
de correção.

## Resultado esperado

O ecrã apresenta **“Documentos submetidos”** e informa que a equipa de coleções
recebeu as correções. Todos os itens satisfeitos ficam resolvidos e a equipa
atribuída é notificada.

A proposta permanece em análise. A entrega das correções não significa que a
proposta tenha sido aprovada.

## Atenção

> Depois de selecionar **“Submeter documentos corrigidos”**, a ligação fica
> inutilizável. Confirme todos os ficheiros antes de concluir.

> O sistema só permite carregar os tipos de documento pedidos pela equipa. Não
> use esta página para enviar documentação adicional que não faça parte da
> correção.

## Se algo não funcionar

| Situação | O que verificar ou fazer |
| --- | --- |
| Aparece **“Ligação inválida ou expirada”** | A ligação pode ter expirado, já ter sido utilizada ou estar incompleta; contacte a equipa de coleções |
| Aparece **“Este pedido já não pode ser editado”** | A proposta já avançou para outro estado; contacte a equipa antes de enviar documentos por outro meio |
| Um ficheiro é recusado | Confirme que é PDF, JPG, JPEG, PNG ou DOCX e que não excede 10 MB |
| **“Carregar ficheiro”** está indisponível | Escolha primeiro um ficheiro válido para o cartão correspondente |
| A conclusão indica que faltam documentos | Reveja todos os cartões e carregue um ficheiro para cada pedido ainda pendente |
| Aparece **“Sem correções de documentos pendentes”** | Não há itens em aberto para esta ligação; não carregue documentação adicional |
| Carregou o ficheiro errado | Não conclua o processo; contacte a equipa se o ecrã não disponibilizar uma forma segura de o corrigir |
