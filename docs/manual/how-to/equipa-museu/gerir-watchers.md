# Como configurar e controlar watchers

## Objetivo

Criar, pausar e retomar a monitorização periódica de retorno científico para
projetos concluídos.

**Disponível para:** COLLECTIONS_MANAGEMENT, CURATORIAL e DIRECTION

**Onde começar:** **“Use of Collections”** > **“Projects”** > **“Watchers”**

**Tempo aproximado:** 3 minutos por projeto

## Antes de começar

O projeto deve estar concluído e conter informação suficiente sobre o
requerente e os objetos, incluindo número de inventário e nome do objeto.

## Criar um watcher

1. Em **“Watchers”**, procure por **“Search reference or title”** e selecione
   **“Search”**.
2. Use **“State”** para mostrar **“Not created”** ou **“Not eligible”**.
3. Se o projeto estiver elegível, indique **“Start date”**.
4. Em **“Interval”**, indique entre 1 e 365 dias.
5. Selecione **“Create”**.
6. Confirme o estado **“Active”** e a data em **“Next execution”**.

## Pausar, ajustar, executar ou retomar

- Num watcher **“Active”**, selecione **“Pause”** para suspender execuções.
- Num watcher **“Paused”**, altere a data ou o intervalo, se necessário, e
  selecione **“Start”** para retomar.
- Para executar uma pesquisa fora do agendamento, abra o projeto pelo título,
  selecione **“Scientific return”** e use **“Search now”**. Se a investigação
  autónoma estiver configurada e disponível, **“Start autonomous search”**
  inicia esse fluxo separado.
- Use o filtro **“Closed”** para consultar watchers já encerrados.

## Encerrar definitivamente

1. Abra o projeto pelo título apresentado em **“Watchers”**.
2. Selecione o separador **“Scientific return”**.
3. Na área de monitorização, selecione o botão **“Close monitoring”**.
4. Leia **“Close monitoring?”** e confirme em **“Close monitoring”**. Para
   manter o watcher, escolha **“Keep monitoring”**.

Um watcher **“Closed”** é permanente, deixa de disponibilizar **“Search now”**
e não pode ser retomado.

## Resultado esperado

O watcher ativo apresenta a próxima execução. Pausar conserva a configuração,
as execuções, os candidatos e as decisões anteriores.

## Atenção

> A monitorização encontra candidatos; não confirma publicações. Cada candidato
> continua sujeito a revisão humana.

> **“Closed”** é terminal. Se existe a possibilidade de retomar a monitorização,
> use **“Pause monitoring”** em vez de **“Close monitoring”**.

## Se algo não funcionar

| Situação | O que verificar ou fazer |
| --- | --- |
| O projeto está **“Not eligible”** | Leia o motivo e complete os dados ou registos em falta no projeto |
| **“Create”** está indisponível | Indique uma data e um intervalo entre 1 e 365 dias |
| Não consegue alterar o watcher | Confirme o papel ativo e que o estado não é **“Closed”** |
| A execução não produziu candidatos | Isso pode ser um resultado válido; reveja o histórico antes de alterar a pesquisa |
