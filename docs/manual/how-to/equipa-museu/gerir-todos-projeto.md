# Como criar e controlar TODOs de projetos

## Objetivo

Criar lembretes pessoais associados a projetos e acompanhar o trabalho aberto
do papel ativo.

**Disponível para:** COLLECTIONS_MANAGEMENT, CURATORIAL, DIRECTION e SYS_ADMIN

**Onde começar:** **“Use of Collections”** > **“Projects”** > **“TODO List”**

**Tempo aproximado:** 2 minutos por item

## Antes de começar

Cada TODO pertence simultaneamente ao utilizador e ao papel ativo. O mesmo
utilizador com outro papel não verá esse item. O texto aceita até 160 carateres.

## Criar um TODO na lista geral

1. Abra **“TODO List”**.
2. Em **“Project”**, pesquise e selecione o projeto.
3. Em **“Item”**, escreva uma ação curta e verificável.
4. Selecione **“Add”**.

## Criar um TODO dentro do projeto

1. Abra o detalhe do projeto e selecione o separador **“TODO List”**.
2. Escreva o lembrete em **“New item”**.
3. Selecione **“Add”**.

## Acompanhar e concluir

- Use **“Open”**, **“Completed”** ou **“All”** para filtrar por estado.
- Depois de selecionar um projeto na lista geral, marque **“Only
  [referência]”** para restringir os resultados.
- Marque a caixa do item para o concluir; desmarque-a para o reabrir.
- Use a ação de remoção apenas quando já não precisar do histórico pessoal.
- No Dashboard, selecione um post-it para abrir o projeto ou **“See all”** para
  regressar à lista completa.

## Resultado esperado

O item aparece junto do projeto e nos filtros adequados. TODOs abertos recentes
também aparecem no Dashboard do mesmo papel ativo.

## Atenção

> TODOs são lembretes pessoais, não tarefas atribuídas a colegas nem eventos
> oficiais do projeto. Trocar o papel ativo muda a lista apresentada.

## Se algo não funcionar

| Situação | O que verificar ou fazer |
| --- | --- |
| **“Add”** está indisponível | Selecione um projeto e escreva um item não vazio com até 160 carateres |
| Um TODO desapareceu | Reveja o filtro, o projeto selecionado e o papel ativo |
| Outro colega não vê o item | O comportamento é intencional: cada TODO pertence ao seu criador e papel |
| O item não aparece no Dashboard | Apenas os TODOs abertos mais recentes são mostrados; use **“See all”** |
