# Como iniciar, utilizar, concluir ou cancelar um projeto

## Objetivo

Acompanhar o ciclo de vida de um projeto criado a partir de uma proposta
aprovada e executar as ações disponíveis ao investigador em cada estado.

**Disponível para:** EXTERNAL responsável pela proposta que originou o projeto

**Onde começar:** **“Use of Collections”** > **“Projects”** > **“My projects”**

**Tempo aproximado:** 5 minutos para iniciar ou concluir; a duração do projeto e
dos seus registos depende da visita

## Antes de começar

Um projeto não é criado manualmente. Quando uma proposta é aprovada, o sistema
cria automaticamente o projeto correspondente com um número no formato
`CUP-XXXXXXXX`.

Para começar:

- inicie sessão com a conta e o papel associados à proposta;
- confirme que o projeto aparece em **“My projects”**;
- reveja o título, o propósito, as datas e a pessoa da equipa atribuída;
- contacte a equipa se os dados ou os objetos associados estiverem incorretos.

## Compreender os estados

| Estado apresentado | O que significa | Ações do investigador |
| --- | --- | --- |
| **“Created”** | Projeto criado, mas ainda não iniciado | Consultar, iniciar ou cancelar |
| **“In progress”** | Visita ou utilização em curso | Preencher registos, acrescentar publicações, concluir ou cancelar |
| **“Completed”** | Projeto concluído | Consultar detalhe, eventos e publicações em modo de leitura |
| **“Cancelled”** | Projeto cancelado | Consultar o histórico em modo de leitura |

## Encontrar e abrir um projeto

1. Abra **“Use of Collections”** > **“Projects”** > **“My projects”**.
2. Use **“Search reference or title”** e **“Search”** para procurar pelo número
   de referência ou título.
3. Navegue com **“First”**, **“Previous”**, **“Next”** e **“Last”**. A página
   apresenta três cartões de cada vez.
4. Selecione o número de referência do projeto ou abra o menu de ações e escolha
   **“Details”**.
5. No detalhe, use:
   - **“Overview”** para consultar propósito, datas, equipa e **“Event log”**;
   - **“Actions”** para iniciar, preencher registos, concluir ou cancelar.

## Iniciar o projeto

Só é possível iniciar um projeto com o estado **“Created”**.

### A partir da lista

1. Em **“My projects”**, abra o menu de ações do cartão.
2. Selecione **“Start”**.
3. Aguarde a atualização do cartão para **“In progress”**.

### A partir do detalhe

1. Abra o projeto e selecione o separador **“Actions”**.
2. Em **“Lifecycle”**, selecione **“Start project”**.
3. Leia a confirmação e selecione novamente **“Start project”**. Para desistir,
   escolha **“Not yet”**.

Ao iniciar, o sistema regista o evento **“STARTED”**. Se o projeto já tiver
objetos e ainda não existir um registo de acesso, este é criado com uma entrada
inicial por objeto. Um projeto sem objetos pode ser iniciado, mas não pode ser
concluído enquanto continuar vazio.

## Utilizar o projeto

Com o estado **“In progress”**, o separador **“Actions”** disponibiliza:

- **“Open access log”** — registar os objetos efetivamente acedidos;
- **“Open occurrence log”** — registar ocorrências relacionadas com os objetos;
- **“Open publication log”** — registar publicações e resultados derivados do
  projeto.

Os cartões de **“My projects”** também apresentam acessos rápidos para
**“Object Access log”** e **“Object Occurrences”** enquanto o projeto está em
curso. O preenchimento destes registos é explicado num guia próprio.

## Concluir o projeto

Para concluir, o projeto tem de estar **“In progress”** e possuir pelo menos um
objeto associado.

1. Abra o projeto e selecione **“Actions”**.
2. Em **“Lifecycle”**, localize **“Complete project”**.
3. Se aparecer **“Add at least one object before completing this project”**,
   contacte a equipa do museu. Apenas a equipa pode associar objetos ao projeto.
4. Selecione **“Complete project”**.
5. Leia a confirmação e selecione novamente **“Complete project”**. Para manter
   o projeto em curso, escolha **“Keep in progress”**.
6. Aguarde até o estado mudar para **“Completed”**.

Depois da conclusão, os registos de acesso e ocorrências deixam de estar
disponíveis para escrita pelo investigador. O registo de publicações continua
consultável, mas novas entradas passam a ser responsabilidade da equipa do
museu.

## Cancelar o projeto

O investigador pode cancelar um projeto em **“Created”** ou **“In progress”**.

1. Em **“My projects”**, abra o menu de ações do cartão.
2. Selecione **“Cancel”**.
3. Leia a confirmação **“Cancel project?”**.
4. Para confirmar, selecione **“Cancel project”**. Para desistir, escolha
   **“Keep active”**.
5. Aguarde até o cartão apresentar **“Cancelled”**.

A interface atual não solicita ao investigador um motivo escrito nesta ação;
regista automaticamente um motivo genérico. Se precisar de deixar uma
justificação institucional, contacte a pessoa da equipa atribuída antes de
cancelar.

## Resultado esperado

- Iniciar muda o projeto de **“Created”** para **“In progress”**.
- Concluir muda-o de **“In progress”** para **“Completed”**.
- Cancelar muda-o de **“Created”** ou **“In progress”** para **“Cancelled”**.
- Cada alteração fica registada no **“Event log”**.
- O requerente é notificado quando o projeto é iniciado, concluído ou cancelado.

## Atenção

> Concluir e cancelar são ações irreversíveis na utilização normal. Um projeto
> concluído ou cancelado deixa de aceitar os registos disponíveis durante a
> execução.

> Cancelar a proposta que originou o projeto também cancela o projeto
> associado, mesmo que este já esteja concluído.

## Se algo não funcionar

| Situação | O que verificar ou fazer |
| --- | --- |
| O projeto aprovado não aparece | Limpe a pesquisa e confirme que está a usar a conta e o papel da proposta aprovada |
| **“Start”** ou **“Start project”** não aparece | O projeto já pode estar em curso, concluído ou cancelado |
| Os registos estão bloqueados | O projeto tem de estar **“In progress”** para o investigador os preencher |
| **“Complete project”** está bloqueado | Confirme o estado e a existência de pelo menos um objeto associado; se faltar, contacte a equipa |
| **“Cancel”** não aparece | Apenas projetos **“Created”** ou **“In progress”** podem ser cancelados diretamente |
| Uma ação apresenta erro depois de outra pessoa alterar o projeto | Atualize a página e confirme o novo estado no **“Event log”** antes de repetir |
