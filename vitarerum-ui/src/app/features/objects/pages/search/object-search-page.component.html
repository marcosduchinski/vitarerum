How search works
Exact Text Approximate

Search runs automatically across the selected searchable columns for each imported file. It checks exact values, contained phrases, text matches and approximate similarities. Semantic search is not enabled yet.

  • Don't worry about accents — "sao paulo" still finds "São Paulo".
  • Small typos are fine — "pantera onca" still finds "Panthera onca".
  • A partial code works too — "024/001" can find "2024/0012".
  • Combine what you remember — "jaguar bocaina" finds objects matching both, even across different fields.
