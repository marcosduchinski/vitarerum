How masks work
YYYY YY MM DD XXXX

A mask combines fixed text, optional date tokens and one final sequence token made from X characters. Only letters, digits, slashes, underscores and hyphens are allowed.

  • VRP-YYYYMMDD-XXXX creates values like VRP-20260730-0001.
  • CUP-XXXXXXXX creates a global eight-digit sequence like CUP-00000001.
  • The X sequence must be the last token and can be up to 12 characters wide.
  • Date tokens decide when numbering restarts: by year, month, day or globally.
